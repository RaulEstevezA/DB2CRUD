# shop-api

REST API generated by [Model2API](https://raulesteveza.github.io/tools/Model2API/) with NestJS. It is a starting point: review it before using it in production.

## Run it

Requires Node.js 22 or later.

```bash
npm install
npm run build
npm start                        # with the variables of .env.example in your environment
```

The API listens on http://localhost:3000. Its contract is in `openapi.yaml`.

## Test it

```bash
npm test
npm run typecheck
```

## Endpoints

| Method | Path | What it does | Success | Access |
|---|---|---|---|---|
| `GET` | `/customers` | List customers | 200 | public |
| `GET` | `/customers/{id}` | Get a customer | 200 | public |
| `POST` | `/customers` | Create a customer | 201 | public |
| `PUT` | `/customers/{id}` | Replace a customer | 200 | public |
| `PATCH` | `/customers/{id}` | Update part of a customer | 200 | public |
| `DELETE` | `/customers/{id}` | Delete a customer | 204 | public |
| `GET` | `/products` | List products | 200 | public |
| `GET` | `/products/{id}` | Get a product | 200 | public |
| `POST` | `/products` | Create a product | 201 | public |
| `PUT` | `/products/{id}` | Replace a product | 200 | public |
| `PATCH` | `/products/{id}` | Update part of a product | 200 | public |
| `DELETE` | `/products/{id}` | Delete a product | 204 | public |
| `GET` | `/orders` | List orders | 200 | public |
| `GET` | `/orders/{id}` | Get an order | 200 | public |
| `POST` | `/orders` | Create an order | 201 | public |
| `PUT` | `/orders/{id}` | Replace an order | 200 | public |
| `PATCH` | `/orders/{id}` | Update part of an order | 200 | public |
| `DELETE` | `/orders/{id}` | Delete an order | 204 | public |

Errors always have the same body: `{"error": {"code": "...", "message": "...", "details": [...]}}`. Invalid requests answer 400.

## Storage

Data is kept in memory while the application runs and is lost when it stops. Bind another implementation of each repository token in its module to use a database.

## Authentication

Every endpoint is public.

## Structure

```text
src/
  main.ts, app.module.ts, app.setup.ts
  common/               errors, validation, lists and authentication
  shared/               enums and embedded objects
  <resource>/           module, controller, service, repository and DTOs of one resource
test/                   one end-to-end test file per resource
openapi.yaml            the contract of the API
```
