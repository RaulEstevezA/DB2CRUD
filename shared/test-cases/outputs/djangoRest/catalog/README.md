# catalog-api

REST API generated by [Model2API](https://raulesteveza.github.io/tools/Model2API/) with Django REST Framework. It is a starting point: review it before using it in production.

## Run it

Requires Python 3.12 or later.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
export $(grep -v "^#" .env | xargs)   # after copying .env.example to .env and filling it in
python manage.py makemigrations
python manage.py migrate
python manage.py runserver
```

The API listens on http://localhost:8000. Its contract is in `openapi.yaml`. The first `makemigrations` writes the migrations of the models; keep them in your repository.

## Test it

```bash
python manage.py test
```

The tests create their own database (set `TEST_DATABASE_URL` to use a running server).

## Endpoints

| Method | Path | What it does | Success | Access |
|---|---|---|---|---|
| `GET` | `/categories` | List categories | 200 | public |
| `GET` | `/categories/{id}` | Get a category | 200 | public |
| `POST` | `/categories` | Create a category | 201 | public |
| `PUT` | `/categories/{id}` | Replace a category | 200 | public |
| `PATCH` | `/categories/{id}` | Update part of a category | 200 | public |
| `DELETE` | `/categories/{id}` | Delete a category | 204 | public |
| `GET` | `/items` | List items | 200 | public |
| `GET` | `/items/{id}` | Get an item | 200 | public |
| `POST` | `/items` | Create an item | 201 | public |
| `PUT` | `/items/{id}` | Replace an item | 200 | public |
| `PATCH` | `/items/{id}` | Update part of an item | 200 | public |
| `DELETE` | `/items/{id}` | Delete an item | 204 | public |

Errors always have the same body: `{"error": {"code": "...", "message": "...", "details": [...]}}`. Invalid requests answer 400.

## Storage

Django ORM on postgresql. A reference to another resource is a foreign key that protects it: deleting an item others refer to answers 409. Embedded objects and lists are stored as JSON fields.

## Authentication

Every endpoint is public.

## Structure

```text
config/                settings, URLs, errors, authentication
api/                   models, serializers, services, views and URLs
tests/                 one test file per resource
openapi.yaml           the contract of the API
```
