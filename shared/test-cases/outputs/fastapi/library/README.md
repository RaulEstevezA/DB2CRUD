# library-api

REST API generated by [Model2API](https://raulesteveza.github.io/tools/Model2API/) with FastAPI. It is a starting point: review it before using it in production.

## Run it

Requires Python 3.11 or later.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env             # then fill in your values
uvicorn app.main:app --reload --env-file .env
```

The interactive documentation is at http://localhost:8000/docs, and the contract in `openapi.yaml`.

## Test it

```bash
pytest
```

The tests call every endpoint with an empty storage.

## Endpoints

| Method | Path | What it does | Success | Access |
|---|---|---|---|---|
| `GET` | `/authors` | List authors | 200 | public |
| `GET` | `/authors/{id}` | Get an author | 200 | public |
| `POST` | `/authors` | Create an author | 201 | public |
| `PUT` | `/authors/{id}` | Replace an author | 200 | public |
| `PATCH` | `/authors/{id}` | Update part of an author | 200 | public |
| `DELETE` | `/authors/{id}` | Delete an author | 204 | public |
| `GET` | `/books` | List books | 200 | public |
| `GET` | `/books/{id}` | Get a book | 200 | public |
| `POST` | `/books` | Create a book | 201 | public |
| `PUT` | `/books/{id}` | Replace a book | 200 | public |
| `PATCH` | `/books/{id}` | Update part of a book | 200 | public |
| `DELETE` | `/books/{id}` | Delete a book | 204 | public |

Errors always have the same body: `{"error": {"code": "...", "message": "...", "details": [...]}}`. Invalid requests answer 400.

## Storage

Data is kept in memory while the application runs and is lost when it stops. Replace the repositories in `app/dependencies.py` to use a database.

## Authentication

Every endpoint is public.

## Structure

```text
app/
  main.py, config.py, errors.py, dependencies.py, validators.py
  schemas/              request and response schemas
  repositories/         storage
  services/             rules of each resource
  routers/              HTTP routes
tests/                  one test file per resource
openapi.yaml            the contract of the API
```
